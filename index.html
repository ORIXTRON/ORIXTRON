MATHEMATICAL FORMULATIONS

Landasan Matematis & Persamaan Statistik Algoritma ORIXTRON

01

Order Book Imbalance (OBI)

Menghitung ketidakseimbangan volume bid/ask pada kedalaman L2 orderbook untuk mendeteksi tekanan institusional sebelum pergerakan harga terjadi.

$$OBI_t = \frac{\sum_{i=1}^{L} V_{i,t}^b - \sum_{i=1}^{L} V_{i,t}^a}{\sum_{i=1}^{L} V_{i,t}^b + \sum_{i=1}^{L} V_{i,t}^a} \in [-1, +1]$$

• V^b, V^a = Volume Bid dan Ask pada kedalaman level $L$

• Eksekusi Beli terjadi ketika $OBI_t > +0.65$ disertai *liquidity sweep*.

02

Gaussian Confluence Score ($P_c$)

Vektor probabilitas gabungan yang menggabungkan pergeseran struktur pasar, sudut momentum, dan matriks korelasi silang antar aset.

$$P_c = \Phi\left(\frac{\mu_{\Delta P} - r_0}{\sigma_G}\right) \cdot \cos(\theta_{mom}) \cdot \det(\mathbf{\Sigma}_{corr})$$

• \Phi(z) = Cumulative Distribution Function (CDF) Gaussian

• Eksekusi order hanya aktif jika $P_c \ge 0.82$

03

Optimal Fractional Kelly Criterion ($f^*$)

Menentukan ukuran posisi yang presisi matematis untuk memaksimalkan pertumbuhan modal jangka panjang tanpa risiko bangkrut (*drawdown control*).

$$f^* = \lambda \times \left( \frac{p \cdot b - (1 - p)}{b} \right) \times \left( 1 - \frac{\sigma_t^2}{\sigma_{max}^2} \right)$$

• p = Probability Win Rate, b = Risk/Reward Ratio

• \lambda = 0.25 (Fractional Half-Kelly Factor untuk stabilitas rendah volatilitas)

04

GARCH(1,1) Volatility Dynamic

Memodelkan *volatility clustering* untuk menyesuaikan *stop-loss* dinamis berdasarkan ekspansi dan kompresi volatilitas pasar.

$$\sigma_t^2 = \omega + \alpha \cdot \epsilon_{t-1}^2 + \beta \cdot \sigma_{t-1}^2 \quad (\alpha + \beta < 1)$$

• \epsilon_{t-1} = Residual shock kuadrat periode sebelumnya

• Menjamin jarak Stop-Loss melepas *market noise* tanpa memperbesar risiko.

import numpy as np
from scipy.stats import norm

# ORIXTRON Mathematical Execution Core
class OrixtronQuantEngine:
    def __init__(self, win_rate=0.68, risk_reward=2.3):
        self.p = win_rate
        self.b = risk_reward
        self.kelly_fraction = 0.25  # Half-Kelly for stability

    def calculate_obi(self, bids_vol, asks_vol):
        """Calculates Order Book Imbalance (OBI)"""
        total_vol = np.sum(bids_vol) + np.sum(asks_vol)
        if total_vol == 0: return 0.0
        return (np.sum(bids_vol) - np.sum(asks_vol)) / total_vol

    def compute_gaussian_confluence(self, delta_p, sigma_g, theta_mom, corr_det):
        """Computes Gaussian Confluence Vector Score (Pc)"""
        z_score = delta_p / sigma_g
        phi = norm.cdf(z_score)
        probability_score = phi * np.cos(theta_mom) * corr_det
        return np.clip(probability_score, 0.0, 1.0)

    def optimal_kelly_size(self, capital, sigma_t, max_sigma=0.05):
        """Calculates Optimal Kelly Position Size with Volatility Penalty"""
        f_raw = (self.p * self.b - (1 - self.p)) / self.b
        vol_penalty = 1.0 - (sigma_t**2 / max_sigma**2)
        f_optimal = self.kelly_fraction * f_raw * np.maximum(0.1, vol_penalty)
        return capital * f_optimal

    def evaluate_signal(self, capital, bids, asks, delta_p, sigma_g, theta_mom, corr_det):
        obi = self.calculate_obi(bids, asks)
        pc = self.compute_gaussian_confluence(delta_p, sigma_g, theta_mom, corr_det)

        if obi > 0.65 and pc >= 0.82:
            pos_size = self.optimal_kelly_size(capital, sigma_g)
            return {"status": "EXECUTE_BUY", "size": pos_size, "obi": obi, "pc": pc}
        return {"status": "HOLD_NO_EDGE", "obi": obi, "pc": pc}

INSTALLATION & SETUP GUIDE

Langkah-demi-Langkah Pemasangan dan Server Deployment

01.

Environment Setup

Pastikan Python 3.10+ dan `pip` telah terinstall pada VPS atau Local Terminal.

python -m venv orixtron_env
source orixtron_env/bin/activate
02.

Install Dependencies

Install pustaka kuantitatif berkinerja tinggi untuk perhitungan korelasi matriks.

pip install numpy scipy pandas ccxt websockets numba
03.

Config API Keys

Buat file `.env` dan masukkan API Secret Key bursa (Binance, Stockbit, OANDA).

EXCHANGE_API="YOUR_API_KEY"
SECRET_KEY="YOUR_SECRET"
04.

Run Quant Engine

Jalankan bot pada daemon process menggunakan `pm2` atau Systemd daemon.

pm2 start orixtron_quant.py --name "ORIXTRON_ENGINE"
