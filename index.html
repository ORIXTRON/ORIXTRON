MATHEMATICAL FORMULATIONS

Empat pilar persamaan stokastik dan mikrostruktur pasar yang menggerakkan mesin keputusan serta materi kuantitatif ORIXTRON.

EQ // 01 L2 MICROSTRUCTURE

Order Book Imbalance ($OBI_t$)

Mengukur asimetri likuiditas antara volume Bid dan Ask pada $L$ level kedalaman buku order untuk mendeteksi akumulasi institusional sebelum price discovery.

$$OBI_t = \frac{\sum_{i=1}^{L} V_{i,t}^b - \sum_{i=1}^{L} V_{i,t}^a}{\sum_{i=1}^{L} V_{i,t}^b + \sum_{i=1}^{L} V_{i,t}^a} \in [-1, +1]$$
• Trigger sinyal beli aktif saat $OBI_t > +0.65$ terkonfirmasi.
EQ // 02 PROBABILITY VECTOR

Gaussian Confluence Score ($P_c$)

Menggabungkan fungsi distribusi kumulatif normal $\Phi(z)$, vektor sudut momentum $\theta_{mom}$, dan determinan matriks korelasi lintas aset.

$$P_c = \Phi\left(\frac{\mu_{\Delta P} - r_0}{\sigma_G}\right) \cdot \cos(\theta_{mom}) \cdot \det(\mathbf{\Sigma}_{corr})$$
• Eksekusi hanya diizinkan apabila $P_c \ge 0.82$.
EQ // 03 CAPITAL ALLOCATION

Fractional Kelly Criterion ($f^*$)

Menghitung ukuran posisi optimal dengan penalti varians volatilitas $\sigma_t^2$ guna memaksimalkan geometric growth rate sekaligus menekan drawdown.

$$f^* = \lambda \times \left( \frac{p \cdot b - (1 - p)}{b} \right) \times \left( 1 - \frac{\sigma_t^2}{\sigma_{max}^2} \right)$$
• Faktor konservatif $\lambda = 0.25$ (Quarter-Kelly).
EQ // 04 VOLATILITY REGIME

GARCH(1,1) Dynamic Variance

Memprediksi klaster volatilitas periode berikutnya ($\sigma_t^2$) untuk mengkalibrasi jarak Stop-Loss dinamis terhadap noise pasar.

$$\sigma_t^2 = \omega + \alpha \cdot \epsilon_{t-1}^2 + \beta \cdot \sigma_{t-1}^2 \quad (\alpha + \beta < 1)$$
• Menjaga stasioneritas varians jangka panjang ($\alpha + \beta < 1$).

import numpy as np
from scipy.stats import norm

# ORIXTRON Institutional Execution Core v4.2
class OrixtronQuantEngine:
    def __init__(self, win_rate=0.684, risk_reward=2.30):
        self.p = win_rate
        self.b = risk_reward
        self.kelly_fraction = 0.25

    def calculate_obi(self, bids_vol, asks_vol):
        total = np.sum(bids_vol) + np.sum(asks_vol)
        return 0.0 if total == 0 else (np.sum(bids_vol) - np.sum(asks_vol)) / total

    def compute_confluence(self, delta_p, sigma_g, theta_mom, corr_det):
        phi = norm.cdf(delta_p / sigma_g)
        return np.clip(phi * np.cos(theta_mom) * corr_det, 0.0, 1.0)

    def optimal_kelly_size(self, capital, sigma_t, max_sigma=0.05):
        f_raw = (self.p * self.b - (1 - self.p)) / self.b
        vol_penalty = 1.0 - (sigma_t**2 / max_sigma**2)
        return capital * self.kelly_fraction * f_raw * np.maximum(0.1, vol_penalty)
